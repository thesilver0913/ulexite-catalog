Ulexite Player 利用規約

VRChat のワールド向けメディアプレイヤー「Ulexite Player」の利用規約を掲示するページです。規約を更新したときも、このページでお知らせします。

規約の正文は VN3ライセンス（和文が正文、英文は参考訳）です。PDF は準備ができしだい、このページに掲載します。下の表は要点のまとめで、正文と食い違う場合は正文が優先されます。

要点

できること
  • Ulexite Player を組み込んだワールドを作成・公開すること（Public を含む）。そのワールドで有料イベントの開催や物品・サービスの販売などの商用の活動を行うこと（個人・法人とも）
  • 改変すること、改変したものを含めて 無償で 再配布すること（受け取った人にも同じ規約が適用されます）
  • 配信・動画・出版物への映り込みや利用
  • Ulexite Player を題材にした二次創作（非営利、および実費程度の頒布）
できないこと
  • Ulexite Player およびその改変版を、単体または他のデータと組み合わせて 有償で配布・販売 すること
  • 改変版に「Ulexite」の名称・ロゴを使うこと、改変版を本家の Ulexite Player であるかのように見せること（改変版は別の名称で配布してください）
  • 政治活動・宗教活動への利用（私的な利用を除く）
問い合わせが必要なことグッズ（有体物）への利用、ソフトウェア製品への組み込み
クレジット表記任意です（表記する場合は「Ulexite Player」）
規約の変更受け取ったバージョンの規約は、後から変わりません。新しいバージョンには新しい規約が適用されます

規約の対象外のもの

  • VizVid（別途導入。MIT License に従います）
  • 同梱するフォント（Noto Sans JP、Sora。SIL Open Font License 1.1 に従います）
  • YouTube のロゴ（Google LLC の商標です。YouTube のブランドガイドラインに従ってのみ使用してください）

YouTube API サービスについて

動画アプリは YouTube API サービスを使用しています。利用者には YouTube 利用規約 が適用されます。Google による情報の扱いは Google プライバシーポリシー、Ulexite での扱いは Ulexite のプライバシーポリシー をご覧ください。
