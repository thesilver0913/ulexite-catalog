Ulexite Catalog プライバシーポリシー

Ulexite Catalog は、VRChat ワールド向けのテレビ「Ulexite TV」に動画の一覧や防災情報（地震・津波・気象の警報・注意報）・天気予報を配る共通サーバーです。YouTube API Services と気象庁ホームページのデータを利用しています。

集めない情報

このサーバーは、VRChat のユーザーや Ulexite TV を導入したワールドの訪問者の個人情報・アカウント情報・端末の情報を集めません（不具合の報告フォームで送られた内容を除きます。下の「不具合の報告フォーム」）。Cookie も使いません。

このサーバーが扱う情報

YouTube Data API から、公開されている動画の ID・タイトル・チャンネル名を定期的に取得し、動画の一覧として公開しています。取得した情報は毎回取り直し、30日以内に更新または削除します。

気象庁ホームページから、発表された地震・津波・気象の警報・注意報の情報と、天気予報・アメダスの観測値を定期的に取得し、そのままの形で配っています（出典：気象庁ホームページ。並べ替え・抜き出しなどの加工をしています）。日の出・日の入り・月の情報は、気象庁のデータではなく、このサーバーが計算したものです。

第三者のサービス

  • 動画の一覧は GitHub Pages から配信されます。配信の際のアクセス記録は GitHub のプライバシーポリシーに従って GitHub が扱います。
  • 動画のサムネイルと動画本体は、VRChat のクライアントが YouTube のサーバーから直接読み込みます。
  • このサービスは YouTube API Services を利用しています。利用にあたっては YouTube 利用規約 が適用されます。Google による情報の扱いは Google プライバシーポリシー をご覧ください。

不具合の報告フォーム

不具合の報告フォームに入力された内容（種類・バージョン・環境・ワールド・起きたこと・エラー）を、不具合の確認と改善に使います。個別の返信はしません。

フォームの送信先は Cloudflare, Inc. のサーバー（Cloudflare Workers・D1）です。IP アドレスは保存しません（スパム対策のため、ソルト付きのハッシュを24時間だけ保持します）。

保存期間は1年、または解決したあとに削除します。連絡先は聞かないので、個人を特定する情報は受け取りません。

削除・開示のご依頼は X の @UlexiteOfficial まで。

お問い合わせ

不具合の報告は公式サイトの報告フォームへ（個別の返信はしません）。そのほかはこのリポジトリの Issues からご連絡ください。

Privacy Policy (English)

Ulexite Catalog is a shared server that provides video lists and disaster information (earthquakes, tsunami, and weather warnings) and weather forecasts to "Ulexite TV", a TV for VRChat worlds. It uses YouTube API Services and data from the Japan Meteorological Agency (JMA) website.

This server does not collect any personal, account, or device information from VRChat users or visitors of worlds that use Ulexite TV (except what is sent through the bug report form, described below), and it does not use cookies.

It periodically retrieves public video IDs, titles, and channel names from the YouTube Data API and publishes them as video lists. This data is refreshed on every run and is updated or deleted within 30 days.

It also periodically retrieves earthquake, tsunami, and weather warning information, weather forecasts, and AMeDAS observations issued by the JMA and redistributes them as issued (source: JMA website; selected and reordered by Ulexite). Sunrise, sunset, and moon information is calculated by this server and is not JMA data.

The lists are served by GitHub Pages; access logs are handled by GitHub under its privacy policy. Thumbnails and videos are loaded directly from YouTube by the VRChat client. By using this service you agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Bug report form. What you enter in the bug report form (type, version, environment, world, what happened, errors) is used to investigate and fix problems. We do not reply individually. The form submits to Cloudflare, Inc. (Cloudflare Workers and D1). We do not store IP addresses (a salted hash is kept for 24 hours for spam protection only). Reports are kept for one year or deleted once resolved. We do not ask for contact details, so no personally identifying information is collected. For deletion or disclosure requests, contact @UlexiteOfficial on X.

Contact: please use the bug report form on the official site for bugs (no individual replies), or open an issue in this repository for anything else.
