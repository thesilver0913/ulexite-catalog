Ulexite Catalog プライバシーポリシー

Ulexite Catalog は、VRChat ワールド向けのテレビ「Ulexite TV」に動画の一覧や防災情報（地震・津波・気象の警報・注意報）を配る共通サーバーです。YouTube API Services と気象庁ホームページのデータを利用しています。

集めない情報

このサーバーは、VRChat のユーザーや Ulexite TV を導入したワールドの訪問者の個人情報・アカウント情報・端末の情報を集めません。Cookie も使いません。

このサーバーが扱う情報

YouTube Data API から、公開されている動画の ID・タイトル・チャンネル名を定期的に取得し、動画の一覧として公開しています。取得した情報は毎回取り直し、30日以内に更新または削除します。

気象庁ホームページから、発表された地震・津波・気象の警報・注意報の情報を定期的に取得し、そのままの形で配っています（出典：気象庁ホームページ。並べ替え・抜き出しなどの加工をしています）。

第三者のサービス

  • 動画の一覧は GitHub Pages から配信されます。配信の際のアクセス記録は GitHub のプライバシーポリシーに従って GitHub が扱います。
  • 動画のサムネイルと動画本体は、VRChat のクライアントが YouTube のサーバーから直接読み込みます。
  • このサービスは YouTube API Services を利用しています。利用にあたっては YouTube 利用規約 が適用されます。Google による情報の扱いは Google プライバシーポリシー をご覧ください。

Privacy Policy (English)

Ulexite Catalog is a shared server that provides video lists and disaster information (earthquakes, tsunami, and weather warnings) to "Ulexite TV", a TV for VRChat worlds. It uses YouTube API Services and data from the Japan Meteorological Agency (JMA) website.

This server does not collect any personal, account, or device information from VRChat users or visitors of worlds that use Ulexite TV, and it does not use cookies.

It periodically retrieves public video IDs, titles, and channel names from the YouTube Data API and publishes them as video lists. This data is refreshed on every run and is updated or deleted within 30 days.

It also periodically retrieves earthquake, tsunami, and weather warning information issued by the JMA and redistributes it as issued (source: JMA website; selected and reordered by Ulexite).

The lists are served by GitHub Pages; access logs are handled by GitHub under its privacy policy. Thumbnails and videos are loaded directly from YouTube by the VRChat client. By using this service you agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.
